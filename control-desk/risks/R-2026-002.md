# Risk Record: Cross-Project Index Misrepresents Source State

## Description

A central index could show stale, invalid, or inaccessible project data as current and trustworthy.

## Controls

- Preserve source repository, commit, hash, parser version, and indexing time.
- Record failed and partial index runs.
- Make stale and unavailable states visible.
- Keep project repositories authoritative.
- Require explicit project registration and visibility boundaries.

## Residual risk

The controls are specified but not yet implemented. The risk remains open until a multi-project dry run demonstrates them.
