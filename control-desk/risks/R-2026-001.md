# Risk Record: Linked Records Become Inconsistent

## Description

Separate Markdown records could reference IDs that do not exist or describe conflicting states.

## Control

The read-only validator checks record IDs, required fields, allowed values, and linked-record existence before the index is trusted.

## Residual risk

The initial validator uses a deliberately small scalar metadata subset and does not yet enforce every semantic rule in the templates.
