# Approval Record: Local Model Observation Analysis Adapter

Approved to implement a local-only adapter that sends a deterministic repository observation bundle to the existing STS AI Gateway and returns a validated, non-authoritative analysis proposal.

## Approved boundary

- Use the existing loopback STS AI Gateway only.
- Send observation facts, not unrestricted repository contents.
- Use a fixed prompt template and bounded generation settings.
- Record provider, model, prompt, input, output, and validation provenance.
- Support dry-run analysis without any model request.

## Excluded boundary

No direct model writes to Markdown, SQLite, Git, repositories, approvals, milestones, or deployments. No public binding, cloud fallback, automatic reconciliation, or automatic state transition is authorized.
