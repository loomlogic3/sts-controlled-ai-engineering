# Milestone Record: SQLite-Backed Read-Only Dashboard Projection

## Mission

Use the approved rebuildable SQLite projection as an optional read source for the cross-project Control Desk dashboard while keeping project Markdown authoritative.

## Acceptance Criteria

- [x] The approved project registry is indexed into SQLite without source-repository writes.
- [x] The renderer can read active records from SQLite.
- [x] The SQLite-backed renderer shows all 8 projects, 132 records, and 78 milestones before this milestone's own records are added.
- [x] Source paths and raw Markdown remain available for detail inspection.
- [x] The database and generated HTML are treated as rebuildable artifacts.
- [x] No editing, approval, execution, deployment, or automatic sync capability was added.

## Lessons Learned

- The SQLite projection and generated dashboard are useful derived views when their rebuild commands remain explicit and manual.
- A zero-byte generated HTML file can look like a renderer failure; checking artifact size and serving the file over HTTP exposed the issue quickly.
- Completion required distinguishing the dashboard’s derived counts from the authoritative Markdown record count and refreshing the projection after control records changed.
