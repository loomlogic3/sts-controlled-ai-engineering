# Milestone Record: Provider-Neutral Repository Observation

## Mission

Make repository work discoverable across ChatGPT, Codex, OpenCode, Gemini, and local STS model sessions without making any model the source of truth.

## Goal and Scope

### In scope

- A deterministic, read-only observer for explicitly registered repositories.
- A versioned JSON observation bundle suitable for local or cloud model review.
- Hashes and provenance for reproducibility.
- Documentation of model limitations and deterministic controls.

### Out of scope

- Automatic record updates or milestone completion.
- Automatic model invocation.
- Repository writes, source-content ingestion, or external network calls.
- Authentication or hosted multi-tenant deployment.

## Acceptance Criteria

- [x] The observer reads only registered repository paths.
- [x] The observer performs no repository writes.
- [x] Repeated observations of the same Git state produce the same state hash.
- [x] Output distinguishes facts from model-supplied interpretation.
- [x] Provider, model, prompt, input, and output provenance fields are defined for future analysis.
- [x] Model limitations and deterministic controls are documented.
