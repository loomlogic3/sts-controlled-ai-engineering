# Milestone Record: Structured Local Model Proposal Output

## Mission

Make local model proposal output reliably conform to a strict schema without allowing model output to become authority.

## Goal and Scope

### In scope

- Evaluate structured-output, grammar-constrained, or schema-constrained generation options for the local model path.
- Define deterministic handling for unsupported or malformed output.
- Verify valid and invalid proposal cases against the existing adapter.

### Out of scope

- Automatic record updates or milestone transitions.
- Treating model output as evidence or approval.
- Cloud fallback, public endpoints, hosted deployment, or repository writes.

## Risks

- A model response could appear authoritative despite passing schema validation.
- Structured-output support may vary by model server and model family.

## Acceptance Criteria

- [x] A supported local generation path produces schema-valid proposal JSON in a repeatable test.
- [ ] Unsupported structured-output requests fail closed.
- [x] Invalid or incomplete output remains non-authoritative.
- [x] The model, prompt, decoding settings, and limitations are recorded.
- [x] No repository, SQLite, approval, or milestone record is changed by model output.
