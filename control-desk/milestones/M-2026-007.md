# Milestone Record: Controlled STS Project Discovery

## Mission

Allow the Control Desk to discover STS project candidates under explicitly approved roots using project manifests, without silently granting indexing authority.

## Scope

- Standard `.sts-project.json` manifest.
- Approved-root discovery configuration.
- Read-only candidate discovery tool.
- Candidate validation and explicit onboarding boundary.

## Out of scope

- Automatic registration in `projects.json`.
- Recursive scanning of arbitrary filesystem locations.
- Reading unregistered project records.
- Automatic sync, approval, dashboard changes, or deployment.

## Risks

- [R-2026-002](../risks/R-2026-002.md) — cross-project index misrepresents source state.

## Acceptance Criteria

- [x] The current project has a valid STS manifest.
- [x] Discovery scans only configured approved roots.
- [x] Discovery recognizes valid manifests and reports whether a Control Desk is ready for indexing.
- [x] Discovery reports invalid candidates instead of indexing them.
- [x] Discovery does not modify `projects.json` or source repositories.
- [x] Explicit human review remains required before onboarding.
