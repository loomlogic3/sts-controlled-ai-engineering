# Milestone Record: Local Tenant-Scoped Read-Only Prototype

## Mission

Demonstrate the smallest reversible implementation of the dual-deployment model: a loopback-only HTTP surface that reads the existing SQLite projection with explicit project scoping.

## Goal and Scope

### In scope

- A standard-library Python HTTP server.
- Read-only SQLite access.
- Health, project listing, and project-scoped milestone endpoints.
- Local verification of isolation and read-only behavior.

### Out of scope

- Authentication or authorization claims beyond local process boundaries.
- Public network binding or hosted deployment.
- Repository connectors or synchronization.
- Any write, approval, execution, or deployment action.

## Acceptance Criteria

- [x] The server binds to loopback by default.
- [x] The database is opened read-only.
- [x] Project-scoped requests return only the selected project’s records.
- [x] Unknown projects return a non-success response.
- [x] No endpoint mutates the database or source repositories.
- [x] The prototype is explicitly labeled non-production.
