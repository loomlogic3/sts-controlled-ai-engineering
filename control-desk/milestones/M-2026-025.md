# Milestone Record: Local Model Observation Analysis Adapter

## Mission

Allow a local STS model to analyze deterministic repository observations and propose reconciliation work without becoming an authority or writing project records.

## Goal and Scope

### In scope

- A CLI that consumes an observation JSON bundle.
- Dry-run prompt generation.
- Optional calls to the existing loopback STS AI Gateway.
- Fixed prompt and bounded generation settings.
- Output and provenance hashing.
- Strict proposal-schema validation.

### Out of scope

- Automatic record updates or milestone transitions.
- Direct repository or SQLite writes.
- Cloud fallback, public model endpoints, or hosted deployment.
- Treating model output as evidence or approval.

## Acceptance Criteria

- [ ] Dry-run produces a stable prompt hash and no network request.
- [ ] Non-loopback gateway URLs are rejected.
- [ ] Missing gateway credentials fail without sending a request.
- [ ] Valid model JSON is schema-validated as a proposal. *(Not demonstrated by the small local model; limitation accepted.)*
- [x] Invalid model output is rejected and marked non-authoritative.
- [ ] Input and output provenance is recorded without exposing credentials.
